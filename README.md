# Mitschrift

Persönlicher Vorlesungs-Recorder (Deutsch/Englisch): nimmt auf, schreibt mit und erstellt Schnellnotizen, alles im Browser.

- **Genau · Whisper:** Spracherkennung läuft auf dem eigenen Gerät (kostenlos, privat).
- **Schnell · Browser:** Spracherkennung des Browsers.
- **Schnellnotizen** ohne KI, optional ausführliche Notizen mit Claude (eigener API-Schlüssel).

Alle Vorlesungen, Fachbegriffe und Schlüssel bleiben im Browser des Nutzers.

## Fachwörterbücher

`terms/` enthält vier Listen, eine pro Zeile. Ein vorangestelltes `!` bedeutet: Begriff wird nur zum Erkennen von Schlüsselbegriffen genutzt, nie zum automatischen Korrigieren.

| Datei | Begriffe |
|---|---|
| `recht-de.txt` | 10.000 |
| `business-de.txt` | 10.000 |
| `recht-en.txt` | 1.446 |
| `business-en.txt` | 1.601 |

Deutsche Einzelbegriffe stammen aus einem Häufigkeitswörterbuch (nur in echten Texten belegte Wörter, ohne Alltagswörter); Abkürzungen und mehrteilige Begriffe sind von Hand ergänzt.
